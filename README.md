# АгроМаркет API

## Запуск

```
npm install
npm run dev        # http://localhost:3000
```

Нужен Node.js 18.11+ (`node -v`). Frontend (agromarket-react) должен быть на http://localhost:5173, иначе CORS заблокирует запросы.

## Эндпоинты

| Метод | Путь              | Описание               | Ответы    |
|-------|-------------------|------------------------|-----------|
| GET   | /api/health       | проверка сервера       | 200       |
| GET   | /api/about        | информация о сервисе   | 200       |
| GET   | /api/products     | товары, ?search=       | 200       |
| GET   | /api/products/:id | один товар             | 200, 404  |
| GET   | /api/orders       | список заявок          | 200       |
| POST  | /api/orders       | новая заявка           | 201, 400  |

Любой другой адрес возвращает JSON `{ "error": "Маршрут ... не найден" }` со статусом 404.

Тело POST /api/orders: `name`, `email`, `quantity` (обязательные, не меньше 10), `phone`, `date`, `comment`.

## Структура

```
agromarket-server/
├── data/          db.json, products.js (загрузка данных)
├── middleware/    logger.js
├── routes/        products.js, orders.js
└── server.js      сборка приложения
```

Порядок в `server.js`: cors -> express.json -> logger -> маршруты -> обработчик 404.

## Лабораторная 5 — ответы

- **Content-Type у res.send и res.json:** `res.send('строка')` отдаёт `text/html; charset=utf-8`,
  `res.json({...})` отдаёт `application/json; charset=utf-8`.
- **Что происходит без next() в middleware:** запрос доходит до логгера и останавливается: ни маршрут,
  ни обработчик 404 не вызываются, ответ не отправляется. Страница «висит» до таймаута
  (в проверке curl завершился по таймауту без кода ответа).
- **Логгер после маршрутов:** запросы к `/api/products` не логируются, а к несуществующим адресам
  (`/abc`) логируются. Express идёт по цепочке сверху вниз: маршрут `/api/products` находит обработчик
  и отправляет ответ, до логгера, который стоит ниже, запрос не доходит. Несуществующий адрес не
  подходит ни одному маршруту, проходит дальше и попадает на логгер.
- **Отправка формы без express.json():** сервер вернул 400 «Поля name, email и quantity обязательны»
  даже для корректной формы. Без `express.json()` тело запроса не разбирается, `req.body` остаётся
  пустым (`undefined`), поэтому после `req.body || {}` все поля пусты и проверка обязательных полей
  не проходит.
